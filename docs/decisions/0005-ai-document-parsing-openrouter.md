# 0005. AI-функція зрізу 4 («розбір документа»): AI SDK + OpenRouter (безкоштовні моделі) + zod

- Статус: прийнято
- Дата: 2026-11-15
- AC: AC-DOCAI-01, AC-DOCAI-02, AC-DOCAI-03, AC-DOCAI-04, AC-DOCAI-05, AC-DOCAI-06, AC-DOCAI-07, AC-DOCAI-08, AC-DOCAI-09

## Контекст

Зріз 4 (WS10) додає AI-функцію: вставлений текст листа-заявки чи кошторису вендора → пропозиція значень (телефон, опис, категорія, терміновість; рядки кошторису й підсумок), яку людина перевіряє й лише тоді зберігає. Вимоги PM зрізу 4 на 2026-11-15 немає: AC `AC-DOCAI-NN` — тимчасові, від розробника, за golden cases PM solomchaak/property-workflows-spec#40 (див. `openspec/specs/document-parsing/`). Обмеження:

- Next.js 16.4 на Vercel Hobby: функція працює до 300 с; Server Action приймає тіло до 1 МБ.
- Модель — безкоштовна через OpenRouter, ключ — власний. Ліміт безкоштовних моделей — 20 запитів/хв і 50/день на акаунт; додаткові ключі ліміту не збільшують. Безкоштовні моделі з'являються й зникають.
- Безкоштовні ендпоінти можуть зберігати запити й навчатися на них → лише синтетичні дані (`555-01xx`, `*@example.test`).
- Відповідь моделі недетермінована, а CI має бути без мережі й без секретів.

## Рішення

- Нові залежності (точні версії, як в наборі курсу): `ai@7.0.162`, `@openrouter/ai-sdk-provider@3.1.0`, `zod@4.6.7`, `server-only@0.0.1`.
- Виклик — `generateText` + `Output.object({ schema })`; схема zod (`src/lib/ai/schema.ts`) має стан `status: ok | refused`; невідоме — `null` (AC-DOCAI-03, AC-DOCAI-06).
- Чиста функція `proposeValues(input, model)` отримує модель параметром; ключ читає лише `src/lib/ai/openrouter.ts` з `import "server-only"`. Змінна — `OPENROUTER_API_KEY`, без `NEXT_PUBLIC_`; у Vercel — Production і Preview. Порожній ключ або пробіли — «ключа немає»: функція недоступна, ручна форма працює (AC-DOCAI-09).
- Ланцюжок моделей (лише `:free`): `google/gemma-4-31b-it:free` → `google/gemma-4-26b-a4b-it:free` → `nvidia/nemotron-3.5-super-vl:free`; `maxRetries` 0–1.
- Тексти відмови, приміток і попередження, а також сума рядків кошторису — у коді, а не в промпті (AC-DOCAI-05, AC-DOCAI-06, AC-DOCAI-07).
- Людина в контурі: Server Action `proposeValues` лише повертає пропозицію; запис — `confirmValues` після дії людини, з повторною валідацією; обидві дії спершу `requireRole(["manager","admin"])` (AC-DOCAI-08).
- Перевірка якості: 10 golden cases PM #40. Офлайн-реплей записаних відповідей — у `npm test` (CI); живий прогін — `npm run eval` вручну зі звітом у `evals/reports/`.

## Розглянуті варіанти

- Claude Agent SDK у функції Vercel — ні: підпроцес Claude Code (~320–342 МБ) не вміщується в пакет функції (до 250 МБ), а потрібен один виклик моделі.
- Пакет `openai` з `baseURL` OpenRouter або `@openrouter/sdk` — ні: немає валідації схемою з типізованими помилками й тестових моделей в одному API.
- `openrouter/free` (випадкова безкоштовна модель) — ні: результат golden cases не відтворюється.
- Платний ключ — ні: курс використовує безкоштовні моделі; перехід — заміна однієї фабрики в `src/lib/ai/models.ts`.

## Наслідки

- Простіше: провайдера й модель міняємо в одному файлі; CI не залежить від мережі та ліміту.
- Складніше: безкоштовна модель може зникнути або впертися в ліміт — інтерфейс показує, що помічник недоступний, а людина заповнює форму вручну. Ланцюжок перевіряємо `npm run ai:models` перед роботою.
- Записи `tests/fixtures/golden/recorded.json` оновлюємо (`RECORD=1 npm run eval`), коли змінюється промпт (`PARSE_PROMPT_VERSION`) або схема.
- Коли PM опублікує вимогу зрізу 4, AC-ID і тексти оновлюються зміною `clarify-document-parsing`; ADR переглядаємо, якщо вимога міняє обсяг (файли, PDF).
