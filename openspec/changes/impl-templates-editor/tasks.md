# Tasks

Кожна група — окремий PR «Реалізація» (`task/<коротко>`); галочки групи ставимо в її PR. Перед кодом сторінок читаємо гайд у `node_modules/next/dist/docs/`. Міграції — лише новими файлами через `npx supabase migration new`, мітка новіша за `origin/main` (`node scripts/check-migration-order.mjs`). Перед комітом і PR: `npm run lint`, `npm run typecheck`, `npm test`, `npm run build`, `npm run ac:coverage`, `npm run spec:check`, `npm run spec:validate`, `npm run check:design`, `npm run check:boundary`. Кожна Server Action починається з `requireRole(...)`, а той першим викликає `getClaims()` (ніколи `getSession()`); роль — з `profiles.role`. У кожній групі: тест на кожен відмовний AC (відмова **і** «дані не змінились»), назва тесту починається з AC ID, і мутаційна перевірка (таблиця «AC → що прибрали → який тест упав»; для ≥2 AC — видимий червоний прогін CI, revert лише після нього; мутуємо лише нову міграцію чи код цієї групи).
